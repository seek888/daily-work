### 2.3 批量与三态（语义必须分离）

| 动作 | 键 | 即时反馈 | 可撤销 | 计数影响 |
|---|---|---|---|---|

| 批量 AI 审查 | `Shift+E` | 每行插入"审查中"骨架；完成 toast `AI 审查完成 3 项 · 查看` | 否 | 不变 |

## 3. 详情页区块顺序与 AI 抽屉 5 态

### 3.1 详情区块顺序（`.dtmain`）

1. `.crumb`：`gp/order-service › 合并请求 › !128 › 已更新 8 分钟前`
2. `.dt1`：标题（16/24 600）+ 右动作组 `一键 AI 审查`(primary) → `在 GitLab 打开`(ghost+external) → `⋯`
3. `.dmeta`：作者/审阅者头像+名 · 源分支 `→` 目标分支（等宽 chip）· 状态徽标组
4. `.blocker`（条件）：`暂不可合并：test:integration 失败，且需要 2 个批准（0/2）`
5. `.card` 流水线（失败 job 置前、耗时、`2 跳过`）
6. `.card` 审批（`0 / 2`、审阅者、代码所有者、规则）
7. `.card` 描述（6 行折叠 → 展开）
8. `.tabs`：概览 / 变更 12 / 讨论 5 / 流水线 3（指示线 2px `label-primary`，非品牌色）
9. 变更页签：`.ftree` 190（`M/A/D` + `+38 −4` + 顶部 `P1 1 / P2 1 / 未覆盖 2`）+ `.diff` 双栏 hunk + `.thread` 行内 AI 锚点
10. `.drawer` 404（§3.2）+ `.toast`（右下 16/38）

### 3.2 AI 抽屉 5 态

| 态 | `.dwhead` 文案 | 主体 | 底部按钮 |
|---|---|---|---|
| **idle**（未运行） | `AI 审查 · 尚未运行` | 空态：sparkle + `还没有审查结论` / `将用「代码审查 · 默认基线 v7」审查 12 个文件，预计 18s` | `开始审查`(primary) · `换提示词`(ghost) |
| **running** | `AI 审查 · 运行中` + `3/12 文件 · 42s` | 3 张骨架卡（`bg-skeleton` 呼吸 1.6s，reduced-motion 关）+ 进度行 | `取消`(ghost) · `在会话中继续` |
| **done** | `AI 审查 · 基线 v7` + `18s · 12 文件` | 结论卡（风险分级 + 建议 + 置信 + 3 段 meter）→ findings×3 → 范围 note×2 → `.ask` | `要求修改` · `批准` · `加入评论 (3)`(primary) |
| **stale**（代码已变） | `AI 审查 · 结论可能过期` + `base 41c2a9 → 7f3b10` | 顶部 banner `!128 已有 3 次推送，此结论基于旧提交` + 结论卡（灰化 40%） | `增量重审`(primary) · `仍按旧结论处理`(ghost) · `关闭` |
| **failed** | `AI 审查 · 失败` | 错误卡：分类标题（`令牌无权限` / `命中限速` / `模型超时` / `输出不合格式`）+ 原文（等宽可复制）+ 一句建议 | `重试`(primary) · `去设置` · `导出日志`(ghost) |

findings 卡字段：`P1/P2/P3` 徽标 + 一句话标题 + `文件:行`（10px 等宽 caption）+ 问题描述 + 证据块（`markdown-code-block`，命中段 `code-diff-added`）+ `证据 N 处 · 置信 0.90` + `定位` / `加入评论`。

写操作闸门：`批准` → 二次确认条 `批准 !128？将通过 GitLab API 提交 approval`（确认/取消）；`加入评论` 逐条返回成功/失败；失败三分类：网络/令牌 → `去设置`、权限不足 → `当前为只读，开启「可写评论」`、GitLab 拒绝 → 原文可复制。

## 4. 提示词页与设置页字段结构

### 4.1 提示词与技能（`.list` + `.editor`）

| 区块 | 字段 | 规格 |
|---|---|---|

| `.edsub` | `v7 · 更新于 … · 作者 · 适用范围 · 被引用 N 次 · 平均耗时` | 11px `label-tertiary` |
| `.varbar` | 可用变量 chips + `已用 4/5 · 校验通过` | 未使用变量 `label-caption`；未知变量报错红 |
| `.edpane` 编辑 | 行号槽 38px + 等宽 11/19 正文 | 变量 `{{x}}` 高亮 `color-mix(business 16%)` + `business-primary` |
| `.edpane` 预览 | 最近试跑渲染：结论 + findings + `12.4k / 200k tokens · 18s` | 无试跑空态 `还没有试跑，用最接近的 MR 跑一次` |
| `.edpane` 版本历史 | `v7 收紧证据要求` + 当前标记 + 作者/时间 + `对比 / 回滚` | 最多保留 20 版 |
| `.edpane` 适用范围 | 项目/组行 + `覆盖层 v2` / `继承基线` | 未列出项目回落全项目基线 |
| `.edfoot` | 校验结果 · 上次试跑摘要 · `格式化` / `另存为副本` | 校验失败时左侧变 `state-error-primary` |

DSH skills 关系：`~/.dsh/skills` 中带 GitLab 元数据的 skill 作为只读源；插件侧只存覆盖层（启用/变量绑定/范围），**不回写 skill 文件**。

### 4.2 设置页（`.spage` 内容 960 居中，分区 24，行 44）

| 分区 | 字段（类型 · 默认 · 校验/降级） |
|---|---|
| **GitLab 连接** | 实例地址（URL · 空 · 须 origin，可含子路径）· PAT（password · 空 · 有 `read_api` 即可读）· 连接测试（按钮 · — · 显示最近成功时间/用户/耗时）· 作用域检查（只读徽标 · — · 缺 `api` 自动降级只读并置灰写按钮） |
| **轮询与静默** | 间隔（select 1/2/5/10/30 分 · 5 分 · ≥1 分，限速退避）· 活跃时段（time range · 09–20）· 静默时段（switch+range · 20–09 + 周末）· 下次同步（只读 + `立即同步`） |
| **项目与组范围** | 订阅范围（chips+添加 · 空 · 至少 1 个，组含子项目）· 排除已归档（switch · on）· 仅指派给我（switch · on） |
| **通知与未读** | 桌面通知（switch · on）· 面板图标未读徽标（switch · on · 关则徽标不显示）· 仅「需我审」提醒（switch · on） |
| **AI 审查** | 模型（select · deepseek-v4）· 并发（select 1–4 · 2）· 单次上限（input 行/文件 · 4000/12 · 超出分片）· 默认提示词（select · 基线 v7） |
| **权限边界** | 只读 / 可写评论 / 可写（批准·合并）（radio · 可写评论 · 可写需 `api`；合并永不自动执行） |

保存：局部即时生效 + 顶部 `保存 N 项 / 恢复默认`；离开有改动时 `Esc` 先放弃。
